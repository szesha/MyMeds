# FoundLoop: SEMO Campus Lost & Found Matcher
## Team Members
- Samia Zaman Esha
- MD Fahad Imam Akash

## Project Abstract
FoundLoop is a campus lost and found website for SEMO students. Students can report something they lost or found and add details like the item name, color, location, date, and description. The system will compare lost and found reports and show possible matches. Students can also search and filter the reports to find an item. Our goal is to make finding lost items on campus easier and more organized.
