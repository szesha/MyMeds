# MyMeds: Medication and Appointment Reminder System

## Team Members
- Samia Zaman Esha
- MD Fahad Imam Akash

## Project Abstract
MyMeds is a simple website that helps users keep track of their medicines and doctor appointments. Users can add their medicines and set the time to take them. They can also mark their medicine as taken. Users can add doctor appointments and see their upcoming reminders in one place. Our goal is to make it easier for users to remember their medicines and important appointments.
